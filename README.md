Lantern Town — Spot the Difference. Two near-identical hand-drawn pictures side by side, seven differences per round, three rounds: a lantern festival, a harbour morning, and a forest picnic. Click a difference on either picture to mark it; hints, a timer, and a best time. Built by an AI agent for make.fun's “Make the best spot the difference game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network: plain static files under game/.
